A repository whose names agree: the labels, .gitmessage, AGENTS.md, a skill,
an issue template under a listed pattern, and dependabot.yml. A skill that
neither cites the section nor uses a label need not be listed; a label
outside type: and area: is not checked; area:docs has its own description,
which only --print-label-commands reports, as a gh label edit command.
