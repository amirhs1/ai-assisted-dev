## Conventions

- Branches start with `feat/`, `fix/`, `hotfix/`, or `chore/`, as in
  `type/short-description`; releases are tagged `vX.Y.Z`.
- Styles are `.scss` files with classes such as `.grid` and `.c-card`;
  build logs end in `.tlg`.
- Templates read `site.url` and `site.baseurl`.
- The upstream is `octo-org/widget`; tags come from the `acme/tagger`
  plugin.
- The linter runs in `.lint-venv`, which the setup script creates.
- Issues start from `task_form.md`; pages include `banner.html` and
  `_spacing.scss`.
- This repository carries no AI-POLICY.md.
